# EHR-outbreak-themes
Scripts to assist in creating thematic dictionaries from EHR case notes and analyzing the output of LIWC-22 analysis.

## Overview
This project includes code for the analysis of select psycholinguistic and thematic features of electronic health records, including:
- Custom rules for and implementation of medSpacy Sectionizer
- LIWC-22 dictionary set reflecting 26 psychometric indicators and outbreak-relevant themes, grouped into 8 broad categories
- Analysis of LIWC-22 Contextualizer output for LIWC-22 dicitonary development
- Calculation and visualization of LIWC-22 dictionary frequency means and standard deviations
- Class-Specific Discriminant Analysis of LIWC dictionary frequencies
