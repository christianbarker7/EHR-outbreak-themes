# EHR-outbreak-themes
Scripts to assist in creating thematic dictionaries from EHR case notes and analyzing the output of LIWC-22 analysis.

## Overview
This repo includes code for the analysis of select psycholinguistic and thematic features of electronic health records, including:
- Custom rules for and implementation of medSpacy Sectionizer
- Analysis of LIWC-22 Contextualizer output
- LIWC dictionary frequency means and sd calculation/visualization
- Class-specific discriminant analysis of LIWC dictionary frequencies
